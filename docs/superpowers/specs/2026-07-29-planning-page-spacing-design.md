# Planning Page Spacing Design

## เป้าหมาย

แก้หน้าแผนการเงินที่คอนเทนต์ชิดขอบจอ โดยเพิ่มพื้นที่ว่างซ้ายและขวาให้สม่ำเสมอ อ่านง่าย และยังใช้พื้นที่ได้เหมาะสมบนหน้าจอทุกขนาด

## แนวทาง

- จำกัดความกว้างของ `.planning-page` ให้แคบกว่าพื้นที่ `.page-content` เล็กน้อยและจัดกึ่งกลาง
- ใช้ระยะขอบแนวนอนแบบ responsive ผ่าน `clamp()` เพื่อให้จอใหญ่มีพื้นที่หายใจ แต่จอมือถือไม่เสียพื้นที่มากเกินไป
- คงโครงสร้าง การ์ด ตาราง ฟอร์ม และลำดับข้อมูลเดิมทั้งหมด
- ที่ความกว้างไม่เกิน 760px ยกเลิกการจำกัดความกว้างเพิ่มเติม เพื่อให้หน้าใช้พื้นที่มือถือได้เต็มที่ภายใน padding หลัก

## การตรวจสอบ

- Style test ต้องยืนยันว่า planning page มีความกว้างสูงสุดและอยู่กึ่งกลาง
- Responsive rule ต้องคืนความกว้างเป็น 100% บนมือถือ
- รัน style test, typecheck และ production build เพื่อป้องกันผลกระทบกับหน้าอื่น
